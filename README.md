# Getting Started

※ まだ改良中です

1. move your raycast workspace

```sh
cd your workspace
```

2. clone your repository

```sh
gh repo clone yuyakinjo/attend-kingoftime
```

3. install dependencies

```sh
bun install --frozen-lockfile
```

4. build

```sh
bun run dev
```

Done!
Please see your raycast.
