# setup-local

Raycast に「King of Time 打刻」コマンドが表示されるまでを案内する。

## 分岐（必ずここで判断してから 1 ファイルだけ読む）

作業ディレクトリで `.git` の有無を確認する。

```sh
git -C . rev-parse --show-toplevel 2>/dev/null
```

| 状況                                                                       | 読むファイル |
| -------------------------------------------------------------------------- | ------------ |
| リポジトリ未取得（clone からやる／初回セットアップ／`bun install` 未実施） | `SETUP.md`   |
| すでに clone 済みで、最新化・再ビルドしたい                                | `UPDATE.md`  |

**両方は読まない。** 該当する 1 ファイルだけを読んで、その手順を実行する。

判断がつかない場合はユーザーに「初回セットアップか、アップデートか」確認

## 共通の前提

- `bun`（1.4.0 以上）と Raycast がインストール済みであること
- `gh` CLI が認証済みであること（clone に使用）
